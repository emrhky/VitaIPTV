# Decoder probe

A small separate test app (not part of Vita IPTV) that checks whether the Vita's hardware H.264 decoder
can be set up for 1080p from a homebrew app. It decodes a tiny embedded clip (solid colour, 4 pictures)
at 720p and 1080p through:

- the public API (what Vita IPTV uses today),
- the firmware's "Internal" entry points, with and without `sceVideodecSetConfigInternal(2)`,
- a "Nongameapp" memory query.

Two VPKs are built: `VitaIPTVProbe.vpk` (normal) and `VitaIPTVProbeU.vpk` (unsafe, no ASLR, memory
expansion), because whether the Internal calls need the unsafe build is part of the question.

```
cd tools/decprobe
cmake -B build && cmake --build build      # -> build/VitaIPTVProbe.vpk, build/VitaIPTVProbeU.vpk
```

On the Vita: start a probe, press X. It restarts itself between steps (so one step cannot affect the
next). If it closes or freezes, start it again: the step is recorded as CRASH and the next one runs.
Results: `ux0:data/VitaIPTV/probe/safe_results.txt`, `unsafe_results.txt` and the `_log.txt` files.

`streams.h` is generated by `make_streams.py` (needs ffmpeg with libx264).
